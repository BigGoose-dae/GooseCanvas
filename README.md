# Goose Canvas

[简体中文](README.md) | [English](README.en.md)

一个独立、轻量、可本地运行的 AI 创作画布。项目只保留 Go 与 Web 两端，不依赖 Java 调度器；Go 服务内置并发任务队列，通过 SSE 向 Web 推送任务状态。

当前版本默认使用：

- SQLite 保存项目、节点、连线、素材元数据和生成任务；无需安装数据库。
- 火山引擎方舟调用 Seedream 图片能力和 Seedance 视频能力。
- 本地文件夹保存上传素材与最终生成结果；调用模型时由 Go 服务编码为 Base64。
- React + Vite + XYFlow 提供项目列表和无限画布。
- Web 界面支持中文和英文切换，语言偏好保存在当前浏览器。

## 已支持

- 创建、删除项目。
- 创建文本、图片、视频节点，拖动节点并连接上下游。
- 上传图片和视频素材到本地目录。
- 文生图、图生图、文生视频、图生视频。
- 文本节点作为下游生成节点的附加提示词。
- 图片、视频任务异步执行；默认最多 4 个并发请求，可在 Web 设置中调整。
- SSE 实时同步任务状态、自动重连，不覆盖正在编辑的节点内容。
- 节点自动保存与保存状态提示；失败草稿保留在浏览器，并支持重试。
- 节点复制、分页生成历史、结果预览和明确的下载入口。
- 项目任务队列，展示排队、提交、生成、归档、完成、失败状态。
- Web 配置模型凭证与并发数，保存即生效。
- 不依赖 TOS；上传文件与生成结果均由 Go 服务管理。
- `APP_NAME`、`APP_LOGO_URL` 和 `APP_REPOSITORY_URL` 品牌入口预留。
- 与 Workshop 一致的基础画布操作：空白处右键添加、右键拖拽平移、左键框选、空格加左键平移、节点拖拽缩放，以及从节点右侧拖线到空白处快速创建下游节点。
- SQLite 模型注册表与可视化模型管理入口；支持添加兼容火山 Ark 图片/视频协议的新模型。

## 运行要求

- Go 1.23+
- Node.js 18+
- 一个可用的火山方舟 API Key

## 本地启动

无需先填写配置文件。启动后打开首页的「设置」，填写方舟 API Key 并保存即可。素材默认保存在 `DATA_DIR/assets`。

开发模式使用两个终端：

```bash
make dev-api
```

```bash
cd web
npm install
npm run dev
```

访问 `http://localhost:5173`。Vite 会把 `/api` 请求代理到 `http://localhost:8080`。

也可以先构建 Web，再由 Go 服务同时提供 API 和静态页面：

```bash
make build
./bin/goose-canvas
```

访问 `http://localhost:8080`。

## 使用方式

1. 在首页创建项目。
2. 进入画布，添加文本、图片或视频节点，也可以直接上传素材。
3. 从素材/文本节点右侧连接点拖到生成节点左侧连接点。
4. 在生成节点填写提示词并选择比例、清晰度、时长等参数。
5. 点击“开始生成”。接口立即返回任务，图片和视频均在后端异步执行；通过 SSE 更新状态，可在「任务队列」查看进度。
6. 生成结果会由 Go 立即下载到本地素材目录，画布不长期依赖模型厂商的临时结果 URL。

画布中的图片和视频节点只展示内容框；选中节点后，在右侧参数面板编辑模型、提示词和生成参数。右键点击节点可重命名、复制、查看生成历史、打开参数或删除。复制保留节点内容和当前素材，不复制连线或自动提交任务。

## 模型管理

内置模型由 [`internal/database/sql/001_seed_models.sql`](internal/database/sql/001_seed_models.sql) 初始化到 SQLite，不再通过 `.env` 配置模型 Key。首页和画布顶部均可进入“模型管理”，添加、编辑、启停或删除自定义模型。

模型记录包含模型 Key、任务类型、供应商、调用协议、允许的输入、默认参数和可选参数。当前基础版内置 `volcengine` 供应商适配器，用户可以直接添加任何兼容 `ark-image-v3` 或 `ark-video-v3` 协议且已在其方舟账号开通的模型。接入其他供应商仍需实现对应 Go 适配器。

## 配置

优先使用 `/settings` 页面。Web 配置保存在 SQLite 中，以 AES-GCM 加密；密钥单独保存在 `data/.settings.key`，文件权限为 `0600`。配置读取接口只返回凭证是否已配置，不回传原值；密码框留空保留现有凭证。

旧版明文数据库配置会在启动时迁移为密文。历史备份不受迁移影响，应自行妥善保管。备份需要同时保存数据库和 `.settings.key`，恢复时缺少密钥将无法解密；不要把这些文件上传到 GitHub、Issue 或公开附件。加密保护单独泄漏的数据库，不能保护已经完全失陷的本机。

从 TOS 版本升级时，数据库中的旧素材元数据会保留，但对象文件不会自动迁移。请在升级前下载需要保留的 TOS 文件；旧素材在新版本中会提示重新上传。

下面的环境变量保留为首次配置与开发兼容入口。保存过 Web 配置后，以数据库配置为准；`APP_ADDR` 和 `DATA_DIR` 始终由启动环境决定。


| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `APP_NAME` | `Goose Canvas` | 平台名称 |
| `APP_LOGO_URL` | 空 | 自定义 Logo URL；为空时按深浅主题显示内置 Logo |
| `APP_REPOSITORY_URL` | 项目 GitHub 地址 | 首页仓库链接 |
| `APP_ADDR` | `127.0.0.1:8080` | Go 监听地址 |
| `DATA_DIR` | `./data` | SQLite、设置密钥和本地素材目录 |
| `VOLCENGINE_API_KEY` | 空 | 火山方舟 API Key |
| `VOLCENGINE_BASE_URL` | 方舟北京地址 | 方舟 API 根地址 |
| `WORKER_POLL_INTERVAL` | `3s` | 异步视频任务的状态查询间隔 |
| `WORKER_TASK_TIMEOUT` | `30m` | 异步任务的本地查询超时 |

Web 设置无需重启；环境变量变更需要重启。不要将真实凭证写入 `.env.example`。SQL 日志不插入参数值，本地环境文件和数据库仅允许所属用户读写。

## 架构

```text
React Canvas ── HTTP（保存 / 提交 / 历史 / 下载）── Go API ── SQLite
      ▲                                            │
      └──────── SSE（状态 / 结果快照）───────────────┤
                                                   ├─ 并发任务执行 ── Ark（Base64 输入）
                                                   └─ 本地素材归档 ── DATA_DIR/assets
```

上传先经过 Go 服务写入本地目录。图生图和图生视频提交前，后端读取素材并生成 `data:*;base64,...` 输入；任务数据库不保存输入的 Base64 正文。模型返回临时 URL 后，Go 服务会立即下载并原子写入本地目录。

## 任务与恢复

- 队列默认最多 4 个并发操作，每项操作独立超时。视频等待下一次轮询时不占执行名额；慢请求不会阻塞其余可用名额。
- SSE 首次连接和每次重连发送最新状态快照，之后由任务变更触发推送，并发送心跳。反向代理须关闭 SSE 缓冲，允许长连接。
- 自动保存按节点串行写入，默认停止输入 600ms 后保存；未保存草稿保留在当前浏览器。正常页面跳转前等待保存完成。
- 查询超时可「继续查询原任务」，结果归档失败可「重新归档」，均不重新提交生成请求。
- 提交结果不确定时不会自动重新提交，避免重复计费；普通失败的「重新提交生成」会创建新的生成记录。
- 不提供取消功能。关闭页面或停止本地查询不代表撤销第三方任务。删除节点也不会取消已提交的生成任务。
- 当前运行中的任务保留其连接配置；新任务采用最新配置。服务重启后从数据库恢复可查询、可归档的任务。

## 当前边界

- 当前为本地单用户版本，没有登录、团队权限和配额系统，请勿直接暴露到公网。
- 单个上传文件最大 50MB，一次生成的输入素材合计最大 50MB，避免 Base64 请求占用过多内存。
- 单个模型生成结果最大 2GB，临时链接下载完成后会原子写入本地素材目录。
- 升级前已存入 TOS 的旧素材不会自动迁移，需要重新上传后才能继续用于生成。
- 当前不提供 Docker 一键启动。
- 任务队列使用 SQLite，适合单机部署；多实例部署需增加数据库级抢占和分布式队列。
- 模型 ID 与参数可能因账号开通范围变化，请以火山方舟控制台实际可用模型为准。
